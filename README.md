# そんなシーンあった？ — 嘘の考察でアニメを「初見」に戻すチャット

アニメの「考察」を装って、本当らしい嘘を刷り込むチャットアプリ。
「過去に戻って初めての状態で作品を見たい」という欲望への代替として、時間を巻き戻す代わりに**記憶の側をミスディレクションする**。2周目を見る前にここで嘘の考察を聞いておくと、既知の作品が少しだけ未知に戻る。

ハックツハッカソン提出物。テーマは「時」。

## 体験

1. 作品を選び、キャラクター「シオリ」に「今日は何について話したい?」と聞かれる
2. 話したい場面を答えると、シオリはその場面の**本物の設定**に、見返せば確かめたくなる**小さな嘘**を混ぜて語る（疑っても認めない）
3. ときどき2人目の「としお」が割り込み、シオリの話（嘘を含む）を前提に深い考察を重ねる
4. 会話を終えたら「答え合わせ」で、本文のどこが本当でどこが嘘だったかが明かされる

嘘はセッション内で記憶され、以後の会話でも矛盾しない。事実は正確でなければならない（間違うと「ただの知らないアプリ」になる）ので、本物の設定は `data/` の作品データと外部資料（Wikipedia）から取る。

## 動かす

Node.js 22.13 以降と、Google AI Studio の Gemini API キーが要る。

```bash
npm install
cp .env.example .env.local   # GEMINI_API_KEY を書く
npm run dev
```

http://localhost:3000 を開く。API キーが無ければ LLM は呼ばれず、定型文で返る。

```bash
npm test          # vitest
npm run lint
npm run build
```

環境変数の一覧と意味は `.env.example` と `AGENTS.md` を参照。

## 構成

| 層 | 選定 |
|---|---|
| フロント / バックエンド | Next.js（App Router）+ TypeScript + Tailwind。Route Handlers から SSE で返す |
| LLM | Gemini（`@google/genai`）。会話・主張の取り出し・話題の特定・切り替わりの判定でモデルを分ける |
| 永続化 | JSON ファイル 1 本（`.data/db.json`）。外部資料の段落の埋め込みだけ sqlite-vec |
| デプロイ | Fly.io（Docker 1 台 + 永続ボリューム） |

作品の知識はコードに書かず `data/<workId>/work.json` に置く。ディレクトリを足せば作品が増える。

会話は1発話ごとに「話題の特定 → 発話解析 → 設定の取り出し → 生成 → 主張の取り出し → 矛盾検査（→ 1回だけ再生成）→ としおの割り込み」を回す。詳しくは `AGENTS.md`（設計の正）と `docs/specs/mvp-spec.md`。

`ml/` は主張の取り出しを手元の小さなモデル（Qwen3-1.7B + LoRA）で行うための学習・評価・推論サーバで、アプリとは別プロセス。無くても Gemini で動く。

## ディレクトリ

```
app/          画面と API（Route Handlers）
components/   チャット・答え合わせ・開発者モードの UI
lib/server/   会話パイプライン・データの読み込み・永続化・外部資料の検索
lib/client/   fetch ラッパー・SSE パーサ
data/         作品データ（コードはこの中身を知らない）
ml/           主張の取り出しの LoRA（学習・評価・推論サーバ）
docs/specs/   仕様書
pictures/     キャラクターの原画・スケッチ
```

## 作品データについて

`data/` の作品データは、各作品の設定を自分の言葉で1文ずつ要約したもので、セリフや本文の転載はしていない。このアプリは作品の公式・関係者とは無関係のファン制作物で、シオリの語る内容は意図的に嘘を含む。
